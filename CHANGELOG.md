# Changelog

## Unreleased

### Added

- Specification v1.2 (French), tech pack v1, physical PostgreSQL model with invariant tests, owner questions in `docs/QUESTIONS.md`.
- Monorepo scaffold: Next.js 16 web app, pg-boss worker, shared packages (contracts, kernel, domain, db, ai, integrations), Biome + ESLint a11y, Vitest, Playwright with axe, Turborepo, CI workflow.
- Dev database on PostgreSQL 18 with pgvector (`npm run db:up`), checksum-tracked SQL migrations (init, auth, integration exchanges, app role grants, fail-closed tenant setting), generated Drizzle schema with a post-pull patch for cyclic foreign keys.
- Contracts: 138 enums proven equal to the SQL CHECK constraints, entity read models, command envelopes with decision levels, approvals, API shapes, fixtures.
- Domain: rent terms, IRL revision, payment allocation and receipt kind, charge allocation and regularisation, loan schedules, deposits, CCA ledger, depreciation, cash bridge, Airbnb payouts; fixtures F01–F10 and T-F11 as tests.
- Db runtime: tenant transactions with RLS and app role, object registry links, hash-chained audit log, idempotent commands, approvals, outbox with SKIP LOCKED claims, external references, redacted integration exchanges, seed.
- Integrations (the SMS channel was evaluated and removed on the owner's decision): Odoo JSON-2 client with rate limit, typed operations, capability snapshot and fake server; S3 storage with local dev driver; Mistral OCR; Gladia; Resend outbound and inbound with Svix verification; INSEE, ADEME, IGN open data; Typst PDF templates.
- AI: Claude client (Bedrock or first-party), extraction schemas with evidence and confidence, French assistant with propose-only tools.
- Worker: outbox dispatch and reconcile, document analysis, inbound email, voice transcription, monthly rent terms, nightly controls, deadlines, Odoo back-sync, PDF rendering, IRL refresh.
- Web: better-auth with organizations and TOTP, correlation id on every request, oRPC contract-first API with OpenAPI, design system on Base UI, screens for Accueil, Patrimoine, Documents, Locations, Finance, Travaux, Inbox, Échéancier, Validations, Ops, and the assistant panel.
- Production compose for `local-nolan-sarl` with memory limits, one-shot migrate service, hourly backups to S3, deploy script.
- Recouvrement (LOY-04, MSG-01): arrears detection job qualifying due, unapplied, in-transit, disputed and out-of-sync situations, graded French reminder templates with a version, the `email` outbox dispatcher sending through Resend behind its idempotence trace, and the `/locations/recouvrement` screen that proposes the next reminder level for approval.
- Odoo rent pipeline (slice 1): lock dates read before every posting so a locked period is refused locally, the rent invoice with separate rent, charges and accessory lines and an analytic distribution per unit, CCA journal entries, supplier bills split from their lines, an expected-version re-check before sending, and a back-sync that turns reconciled moves into payments and opens an exception on a divergence.
- États des lieux (EDL-01 to EDL-03): room-by-room mobile capture, furnished inventory, entry/exit comparison and deposit settlement where a missing item never becomes a retention on its own.
- Charge regularisation and rent revisions (CHA-01, CHA-02, IRL-01): versioned allocation keys, frozen and reproducible runs, individual statements as PDF, revision proposals with the unrounded rent kept, the notification letter, and `revise_rent` writing the new term version and invalidating stale prepared commands.
- Insurance and claims (ASS-01, SIN-01): policies with expiry deadlines, attestation matching from the inbox behind four explicit checks, claims with linked expenses and indemnities read from the ledger.
- Short-term rentals (AIR-01 to AIR-03): listings, bookings, stays and payouts as distinct objects, CSV import mapped by header name with a versioned mapping and total check, grouped payout reconciliation, iCal availability with an hourly polling job whose bookings carry zero amounts by rule.
- Finance read models (IMM-01, IMM-02, CRE-02, BAN-01): asset register with per-asset durations and land excluded, loan schedules with versions, insurance basis stored per loan and compared with the observed premiums, bank balances copied from the ledger's journal and labelled by their source, acquisitions (ACQ-01) converted exactly once through the command path.
- Search and memory (MEM-01, MEM-02, IA-06): incremental indexing job filling text and vectors, a search screen that says how much of the corpus is covered, rule proposals from repeated confirmations shown on the inbox and activated only through approval.
- Local AI in production shape: PDF pages rasterised with poppler for the vision model, model health in readiness checks without gating the app, embeddings through Ollama at the schema's 1024 dimensions, an opt-in evaluation harness scoring values and evidence.
- Hardening: production database roles without superuser or BYPASSRLS, two-factor enrolment screen, per-route rate limits, a content security policy that now covers the theme script, RGPD retention rules with a purge job and a per-person export, a durable IndexedDB capture queue that survives a closed tab.
- Schema: the legal entity's registered office and contact (migration 0007), the ledger bank balance and the loan insurance basis (migration 0008); the parity test now reads every migration.
- Deployment: restricted roles in the production compose, an optional Traefik stack, `docs/runbook.md`, `docs/rgpd.md`, `docs/ai-eval.md`.
- Browser tests run against the production build in CI (`scripts/start-standalone.sh`): the dev server compiled each route on first hit slower than the runner's timeouts. Found on the way: `upgrade-insecure-requests` and HSTS now follow the app's URL scheme rather than the environment name, since WebKit upgrades `localhost` and then loads no script; better-auth's own limiter and the local storage driver are switchable for a production build under test; a retried upload reuses the document still waiting for its bytes instead of creating a twin.
